Manage permissions on LinkedIn ↗
Administrator setup
  1. Create a LinkedIn developer application and enable “Sign In with LinkedIn using OpenID Connect.”
  2. Register the website’s exact HTTPS callback address ending in /auth/linkedin/callback.
  3. Configure the client ID, callback address, client secret, and encryption key on the server using the deployment guide.

Never paste passwords, client secrets, or access tokens into this page.
